🚀 Telecom Network Performance & Quality Analysis Dashboard 📊

Excited to share my latest data analytics project focusing on telecom network performance, user traffic, and environmental impact!

In this project, I analyzed key network performance metrics—including download/upload speeds, latency, connected user density, and congestion levels—to evaluate overall network health and reliability.

Key Features & Insights:
🔹 Network Quality Score: Developed a dynamic metric incorporating speeds and latency to quantify overall network efficiency.
🔹 Weather Impact Analysis: Examined how environmental factors (Clear, Rain, Snow, Storm) influence latency, network congestion, and signal performance.
🔹 Tower Performance Grid: Identified low-performing cell towers and localized network bottlenecks to highlight key optimization targets.
🔹 Time-Series Monitoring: Tracked hourly performance trends to pinpoint peak congestion hours and capacity demands.

🛠 Tools Used: Tableau / Power BI, Data Analytics, Metrics Calculation, Dashboard Design.
